# 05 — العلاقات والأحداث

> هذا الملف يجمع: أنواع العلاقات، أنواع الأحداث، علاقة الحدث بالتحول، السببية والعلاقات العليا.  
> الهدف: تثبيت الخريطة المفهومية، دون الدخول في Taxonomy تنفيذية أو مخطط بيانات.

---

## أولًا — أنواع العلاقات

> العلاقات ليست نوعًا واحدًا، بل **طبقات**. ولا تتكون شبكة المعنى إلا بتشابك هذه الطبقات.

1. **العلاقات الوجودية (Ontological Relations)** — تحدد ما الشيء وما انتماؤه. مثل: إنسان ← كائن حي، شجرة ← نبات.
2. **علاقات الهوية (Identity Relations)** — استمرار الكيان مع تغيره. مثل: الطفل ← الشيخ، الماء ← البخار.
3. **علاقات الجزء والكل (Part-Whole Relations)** — اليد جزء من الإنسان، الباب من البيت، الحرف من الكلمة.
4. **العلاقات المكانية (Spatial Relations)** — فوق، تحت، داخل، خارج، قرب، بعد، أمام، خلف.
5. **العلاقات الزمانية (Temporal Relations)** — قبل، بعد، أثناء، بداية، نهاية، استمرار، تكرار.
6. **العلاقات السببية (Causal Relations)** — النار سببت الاحتراق، الضرب سبب الكسر. وتشمل: السبب، الشرط، المانع، المقتضي، المرجّح، المحفّز.
7. **العلاقات الحدثية (Event Relations)** — الفاعل ↔ الفعل، الفعل ↔ المفعول، الحدث ↔ الزمان، الحدث ↔ المكان.
8. **العلاقات الدلالية (Semantic Relations)** — الترادف، التضاد، العموم، الخصوص، الإطلاق، التقييد.
9. **العلاقات السياقية (Contextual Relations)** — معنى الكلمة بحسب الجملة، تغير المعنى بالمقام، تغير الإشارة بالمتكلم.
10. **العلاقات الإدراكية (Perceptual Relations)** — الغموض، التشابه، التمييز، الترجيح، التعيين.
11. **العلاقات النفسية (Psychological Relations)** — الحب، الخوف، النية، الرغبة، القصد. **(طبقة توسعية مؤجلة.)**
12. **العلاقات الاجتماعية (Social Relations)** — الملكية، التبعية، السلطة، القرابة، الجوار. **(طبقة توسعية مؤجلة.)**
13. **العلاقات الرياضية (Mathematical Relations)** — التناسب، التكرار، الاحتمال، الكثافة، التدرج، الشبكية.

> **النتيجة:** المعنى لا يُبنى من الكلمات، بل من **شبكة علاقات متعددة الطبقات**.

### الحرف كمُظهِر علاقات

في العربية، الحرف لم يعد "أداة" فقط، بل **مُظهِر علاقات**:

| الحرف | العلاقة |
|---|---|
| من | ابتداء / تبعيض / بيان |
| إلى | انتهاء / اتجاه |
| في | احتواء |
| على | استعلاء |
| عن | مجاوزة |
| اللام | ملكية / اختصاص |

(تفصيل الحروف بوصفها لغة في `06_Arabic_Language_Layer.md`.)

## ثانيًا — أنواع الأحداث

> الحدث هو **لحظة الحركة** داخل النظام.  
> الحدث = وقوع تحول أو تأثير أو انتقال على كيان أو أكثر داخل زمن وسياق وعلاقات.

1. **الحدث الفيزيائي** — سقط، انكسر، احترق، ذاب.
2. **الحدث الحركي** — ذهب، جاء، اقترب، ابتعد، دخل، خرج.
3. **الحدث الإدراكي** — رأى، سمع، لاحظ، أدرك.
4. **الحدث العقلي** — فهم، ظن، تيقن، استنتج، تذكر.
5. **الحدث النفسي** — أحب، خاف، غضب، اطمأن. **(توسعة.)**
6. **الحدث اللغوي** — قال، كتب، نادى، سأل، أجاب.
7. **الحدث الاجتماعي** — تزوج، بايع، تصالح، حارب. **(توسعة.)**
8. **الحدث القانوني** — حكم، أباح، منع، ورث، وقّع. **(توسعة.)**
9. **الحدث الاقتصادي** — باع، اشترى، دفع، استثمر. **(توسعة.)**
10. **الحدث السببي** — حدث يولد حدثًا آخر (ضرب → كسر).
11. **الحدث الطبيعي** — مطر، زلزال، فيضان، ريح.
12. **الحدث البيولوجي** — وُلِد، نَمَا، مرض، مات.
13. **الحدث التدريجي** — تعلم، نضج، ضعف، ازداد.
14. **الحدث اللحظي** — انفجر، سقط، صرخ.
15. **الحدث الدوري** — تعاقب الليل والنهار، الفصول، النبض.
16. **الحدث المقصود** — كتب، صنع، خطط.
17. **الحدث غير المقصود** — انزلق، نسي، سقط.
18. **الحدث الفردي** — كسر الزجاج مرة واحدة.
19. **الحدث المتكرر** — طرق الباب مرارًا.
20. **الحدث المركب** — بنى البيت = جلب المواد + رفع الجدران + تركيب السقف + الطلاء.

### بنية الحدث

كل حدث يمكن تحليله إلى:

| العنصر | المعنى |
|---|---|
| الفاعل | من أحدث الفعل |
| المتأثر | ما وقع عليه الحدث |
| السبب | لماذا وقع |
| الشرط | ما الذي سمح بوقوعه |
| المانع | ما الذي قد يمنعه |
| الزمن | متى وقع |
| المكان | أين وقع |
| الأداة | كيف وقع |
| النتيجة | ماذا نتج |
| الأثر | ما الذي تغيّر |
| الاحتمال | درجة تحقق الحدث |

### الزمن داخل الحدث

الحدث ليس نقطة، بل بنية زمنية:
> تهيئة → بداية → استمرار → ذروة → نهاية → أثر لاحق.

### العلاقات بين الأحداث

| العلاقة | المثال |
|---|---|
| سبب ونتيجة | ضرب → كسر |
| تزامن | تكلم وهو يمشي |
| تعاقب | دخل ثم جلس |
| احتواء | الحرب تحتوي معارك |
| ترجيح | المطر يرجح الانزلاق |

## ثالثًا — العلاقة بين الحدث والتحول

> **الفعل = تحول.**  
> لكن **ليست كل التحولات من نوع واحد.**

أنواع التحولات داخل النظام:

1. **التحول المكاني** — ذهب، جاء، اقترب، ابتعد، دخل، خرج.
2. **التحول الفيزيائي** — انكسر، احترق، ذاب، تجمد، تبخر.
3. **التحول الكمي** — ازداد، نقص، تضاعف، كبر، صغر.
4. **التحول الكيفي** — تحسن، فسد، ضعف، قوي، نضج.
5. **التحول الزمني** — بدأ، استمر، انتهى، تكرر، عاد.
6. **التحول الإدراكي** — عرف، فهم، ظن، تيقن، أدرك.
7. **التحول النفسي** — أحب، خاف، اطمأن، غضب، حزن. **(توسعة.)**
8. **التحول الاجتماعي** — تزوج، ملك، باع، ورث، حكم. **(توسعة.)**
9. **التحول القانوني** — أباح، منع، حكم، أذن، حرّم. **(توسعة.)**
10. **التحول السببي** — ضرب فكسر، أحرق فأتلف، دفع فسقط.
11. **التحول الاحتمالي** — ظن → رجّح → تيقّن.
12. **التحول الدلالي** — عين → عضو بصري → عين ماء → جاسوس.
13. **التحول الهوياتي** — خشب → رماد، طفل → شيخ، ماء → بخار.
14. **التحول الجزئي** — جرح اليد، كسر الباب، قص الشعر.
15. **التحول الكلي** — احترق البيت، مات الإنسان، تحطم الزجاج.
16. **التحول الدوري** — الليل والنهار، الفصول، النمو والموت.
17. **التحول التدريجي** — كبر، تعلم، نضج، ضعف.
18. **التحول اللحظي** — انفجر، سقط، مات (في لحظة الحدث).
19. **التحول المقصود** — بنى، كتب، صنع.
20. **التحول غير المقصود** — انزلق، نسي، سقط.

> **النتيجة الكبرى:** الفعل في المشروع لم يعد "كلمة تدل على حدث وزمن"، بل **محرك تحول داخل شبكة علاقات وسياقات**.

### البنية الجديدة للفعل

> فعل = تحول + زمن + كيانات + علاقات + سببية + سياق + أثر + درجة احتمال.

ويمكن مستقبلاً تصنيف الأفعال العربية ليس بـ (ماضٍ/مضارع/أمر) فقط، بل أيضًا بنوع التحول:

| الفعل | نوع التحول |
|---|---|
| كسر | فيزيائي |
| ذهب | مكاني |
| عرف | إدراكي |
| أحب | نفسي |
| ملك | اجتماعي / قانوني |
| ازداد | كمي |
| تحسن | كيفي |

## رابعًا — السببية والعلاقات العليا

السببية في هذا المشروع ليست عاملًا واحدًا، بل **شبكة عناصر** تحكم وقوع الحدث.

| العنصر | الوظيفة |
|---|---|
| السبب (Cause) | ما يؤدي إلى وقوع الحدث أو يزيد احتمال وقوعه |
| العلة (Underlying Principle) | التفسير العميق أو القانون الداخلي للحدث |
| الشرط (Condition) | ما يلزم لتحقق الحدث |
| المانع (Constraint) | ما يمنع تحقق الحدث رغم وجود أسبابه |
| المقتضي (Driver) | ما يدفع الحدث نحو الوقوع |
| المرجّح (Biasing Factor) | ما يجعل أحد الاحتمالات أقوى من غيره |
| المهيّئ (Enabler) | ما يجهز البيئة المناسبة للحدث |
| المحفّز (Activator) | ما يسرّع الحدث أو يفعّله بعد تهيئته |
| القانون الحاكم (Governing Law) | النظام الذي تنتظم به العلاقات والتحولات داخل مجال معين |

> هذه ليست تصنيفات معجمية، بل **عناصر معمارية** لتحليل أي حدث داخل النظام.

## النتيجة المعمارية لهذا الملف

- الكيانات = **عُقَد المعنى**.
- العلاقات = **روابط المعنى**.
- الأحداث = **حركة المعنى**.
- التحولات = **ديناميكية المعنى**.
- السببية والعلاقات العليا = **القوانين الحاكمة لحركة المعنى**.
