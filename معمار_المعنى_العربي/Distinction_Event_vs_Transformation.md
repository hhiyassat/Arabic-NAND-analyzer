## 1. السُّؤال

كَيف نُفَرِّق عَمَليًّا بَين:
- **Event (الحَدَث):** واقِعَة في زَمن مُحَدَّد
- **Transformation (التَّحَوُّل):** انتِقال مِن حالَة إلى حالَة

هَل كُلّ تَحَوُّل حَدَث؟ نَعَم. هَل كُلّ حَدَث تَحَوُّل؟ **لا.**

---

## 2. التَّمييز العَمَليّ

### Event = «شَيء وَقَعَ»

- **شَكله الأَدنى:** فِعل + فاعِل (+ زَمَن وُقوع)
- **يَترُك أَثَرًا** لَكِنَّه لا يَلزَم تَغيير حالَة الفاعِل أَو المَفعول
- **أَمثِلَة:**
  - «قَرَأَ زَيدٌ الكِتابَ» — حَدَث قِراءَة (زَيد لَم يَتَغَيَّر بِنيَويًّا)
  - «جاءَ المَطَر» — حَدَث ظاهِرَة (لا تَحَوُّل في «المَطَر» نَفسه)
  - «قالَ زَيدٌ كَلامًا» — حَدَث قَول

### Transformation = «شَيء صارَ»

- **شَكله الأَدنى:** كِيان مَع حالَة (قَبل) وَ حالَة (بَعد)
- **يَلزَم تَغيير حالَة** الكِيان (المَوضوع)
- **يَتَطَلَّب فِعل تَحَوُّليّ:** صارَ، أَصبَحَ، تَحَوَّلَ، انْقَلَبَ، عادَ، رَجَعَ، اسْتَحالَ
- **أَمثِلَة:**
  - «صارَ الفَقيرُ غَنيًّا» — تَحَوُّل (state_before=فقير، state_after=غني)
  - «أَصبَحَ الطَّقسُ بارِدًا» — تَحَوُّل (cold ← warm)
  - «انْقَلَبَ الماءُ ثَلجًا» — تَحَوُّل (state_before=ماء، state_after=ثلج)

---

## 3. القاعِدَة الحاسِمَة

```
Transformation = Event × StateChange

      كُلّ تَحَوُّل حَدَث (لِأَنّه واقِعَة).
      لَكِن لَيسَ كُلّ حَدَث تَحَوُّلًا.
```

في schema الكود:

```python
@dataclass
class Event:
    type: str               # نَوع الحَدَث (قَول، قِراءَة، حَرَكَة...)
    agent: Optional[str]    # الفاعِل
    patient: Optional[str]  # المَفعول
    instrument: Optional[str]
    time: Optional[str]
    location: Optional[str]
    manner: Optional[str]
    result: Optional[str]
    # ... ProofObject metadata

@dataclass
class Transformation(Event):
    """تَحَوُّل = Event + StateChange — يَرِث Event."""
    subject: str              # الكِيان المُتَحَوِّل
    state_before: str         # الحالَة السَّابِقَة
    state_after: str          # الحالَة اللاحِقَة
    transformation_verb: str  # الفِعل التَّحَوُّليّ (صار، أَصبَح...)
```

## 4. الِاختبار السُّلوكيّ (10 جُمَل)

| # | الجُملَة | Event | Transformation | السَّبَب |
|---|---|---|---|---|
| 1 | قَرَأَ زَيدٌ الكِتابَ | ✓ | ✗ | لا state change في زَيد |
| 2 | صارَ الفَقيرُ غَنيًّا | ✓ | ✓ | فَقير → غَنيّ |
| 3 | جاءَ المَطَر | ✓ | ✗ | لا state change في المَطَر |
| 4 | أَصبَحَ الطَّقسُ بارِدًا | ✓ | ✓ | حار → بارِد |
| 5 | ضَرَبَ زَيدٌ عَمرًا | ✓ | (جُزئيّ) | عَمرٌو قَد يَتَأَلَّم (state) |
| 6 | تَحَوَّلَ الماءُ ثَلجًا | ✓ | ✓ | ماء → ثَلج |
| 7 | كَتَبَ زَيدٌ كِتابًا | ✓ | (إِنشاء) | الكِتاب لَم يَكُن، صارَ |
| 8 | مَشَى الرَّجُلُ | ✓ | ✗ | حَرَكَة لا تَحَوُّل |
| 9 | ماتَ الشَّيخُ | ✓ | ✓ | حَيّ → مَيِّت |
| 10 | عَلِمَ زَيدٌ الخَبَرَ | ✓ | ✓ | جاهِل → عالِم بِالخَبَر |

**5/10 = events فَقَط، 5/10 = transformations كَذلِك.**

## 6. مُلَخَّص لِلِاستِدلال البَرمَجيّ

```
ALGORITHM detect_event_or_transformation(sentence):
    events = []
    for verb in extract_verbs(sentence):
        e = Event(type=verb.lemma, agent=..., patient=..., ...)
        events.append(e)

        if verb.lemma in transformation_verbs_lexicon:
            # حَدَث تَحَوُّليّ → نُحَدِّثه إلى Transformation
            subject = e.agent or e.patient
            state_after = extract_predicate_complement(sentence, verb)
            state_before = "—"  # ضِمنيّ، يَتَطَلَّب سِياق
            t = Transformation(
                **e.__dict__,
                subject=subject,
                state_before=state_before,
                state_after=state_after,
                transformation_verb=verb.lemma,
            )
            events.append(t)
    return events
```

**Certificate:** فِعل في الـ lexicon + خَبَر بَعده → Transformation
**Hypothesis:** فِعل في الـ lexicon لَكِن بِلا خَبَر صَريح
**Zero:** فِعل لَيسَ تَحَوُّليًّا → Event فَقَط

## 8. النَّتيجَة الدُّستوريَّة

> **Event = (verb + arguments + time)**
> **Transformation = Event + (subject + state_before + state_after)**
> **القاعِدَة:** Transformation **يَرِث** Event، لَيسَ بَديلًا عَنه.
