## ٢. الفرق العملي بين الادعاءَين

| المحاكاة التحليلية الشفافة القابلة للحوكمة | محاكاة الفهم البشري |
|---|---|
| كل قرار له مصدر معجمي أو منطقي صريح | الفهم ادعاء غير قابل للتفكيك |
| كل ادعاء يَحمل نسبة ثقة محسوبة | الفهم لا يُقاس |
| كل قراءة بديلة محفوظة قابلة للاسترجاع | الفهم نتيجة واحدة لا بدائل |
| كل خطوة قابلة لِلنَقض من المستخدم | الفهم لا يُنقَض |
| القرارات قابلة للتدقيق آليًا | الفهم يُختبَر بشريًا فقط |
| الادعاء يُحدّ بما يمكن قياسه | الادعاء فلسفي مفتوح |
| ✅ قابل للتحقق والقياس | ❌ ادعاء فلسفي غير قابل للإثبات |

## ٣. الالتزامات الأربعة الناتجة عن هذا الإعلان

### الالتزام الأول — Source-of-Claim

كل ادعاء يَصدر عن المعمار **يَجب أن يُرفَق بمصدره**: قاعدة، بيانات، نموذج، أو استدلال صريح. لا "يعلم النظام" بدون مرجع. كل سطر إخراج له مرجع قابل للتتبع إلى:
- ملف بيانات (CSV/Excel) مع رقم الصف
- قاعدة منطقية مع رقم السطر في الكود  
- خطوة pipeline مع اسم الـ step
- ادعاء سابق (recursive provenance)

### الالتزام الثاني — Confidence-of-Claim

كل ادعاء **يَجب أن يَحمل نسبة ثقة** في المجال `[0, 1]`. لا "نعم/لا" مطلقة. النسبة محسوبة من:
- تكرار البيانات (frequency-based)
- قوة المطابقة (match strength)
- عدد الأدلة المتوافرة
- وجود تعارض أو غيابه

### الالتزام الثالث — Alternatives-Preserved

القراءات البديلة **تُحفَظ ولا تُحذَف**. عند الغموض، يَنتج المعمار `list[Reading]` مرتَّبة بنسب الثقة، لا قراءة واحدة. المستخدم يَختار. الـ winner-takes-all مرفوض دستوريًا.

### الالتزام الرابع — Reversible-Pipeline

أي قرار في الـ pipeline **يُمكن نَقضه يدويًا**، والنتيجة تُعَاد حسابها من تلك النقطة فما بعد. كل قرار مُسجَّل في audit trail قابل للاسترجاع. الـ pipeline ليس "صندوقًا أسود" يتم استدعاؤه مرة واحدة، بل سلسلة قرارات يمكن التراجع عن أي منها.

## ٤. ما يَخرج عن النطاق صراحةً

بفضل هذا الإعلان، يَنحلّ التزام المعمار بِما يَلي — **لا يَفعله، ولا يُلام على عدم فعله:**

| المُسْتَبعَد | السبب |
|---|---|
| التفسير القرآني (Tafsir) | يَتطلب اجتهادًا بشريًا، لا قواعد رياضية |
| التقييم البلاغي والإعجاز | لا متري موضوعي |
| الاستنباط الفقهي | يَتطلب أصول الفقه وقياسًا اجتهاديًا |
| تقدير النية الباطنة للمتكلم | فلسفيًا غير محسوم |
| فهم الاستعارة والمجاز | research frontier، غير محلول للعربية |
| التقييم الجمالي/الأدبي | ذاتي بطبيعته |
| الادعاء بـ "الفهم" أو "الإدراك" | ادعاء فلسفي خارج النطاق التقني |
| المحاكاة العاطفية | لا قياس |
| الاستدلال المضاد للواقع | محدود رياضيًا |
| السخرية والتورية | تتطلب نموذجًا اجتماعيًا-ثقافيًا غنيًا |

**القاعدة:** لو سُئل المعمار "هل تَفهم هذه الآية؟" — الجواب الدستوري الصحيح: "أنا لا أَفهم، بل أُحلّل. ها هو التحليل، ومرفقًا به مصادري، وثقتي في كل قرار، والقراءات البديلة، وحدود ما يمكنني قوله. القرار النهائي لك."

## ٥. ما يَدخل في النطاق وتُلام على عدم فعله

| المُلتَزَم به | المعيار |
|---|---|
| تحليل لغوي صرفي ونحوي شفاف | accuracy ≥ 90% على نصوص قياسية |
| تصنيف الكلمات (اسم/فعل/حرف) | accuracy ≥ 95% |
| استخراج الجذور والأوزان | coverage ≥ 80% على القرآن |
| الكشف عن الإحالة (داخل الفقرة) | accuracy ≥ 70% — حد M3 |
| كشف نوع الخطاب (قول/أمر/استفهام) | accuracy ≥ 85% — حد M1 |
| استخراج العلاقات السببية والغائية | precision ≥ 80% — حد M3 |
| استخراج الكميات والوحدات | accuracy ≥ 95% — حد M4 |
| تتبع كل قرار إلى مصدره | 100% — لا استثناء |
| إعطاء نسبة ثقة لكل ادعاء | 100% — لا استثناء |
| حفظ القراءات البديلة | 100% — لا استثناء |

## ٦. المعايير الرياضية الواجبة

نتيجة هذا الإعلان، تَدخل الفروع الرياضية التالية كـ **متطلبات دستورية لا اختيارية:**

1. **نظرية الاحتمالات** — لِحساب الثقة
2. **نظرية المعلومات** — لِقياس الغموض (entropy)
3. **نظرية الرسوم البيانية** — للإحالة والتبعية
4. **المنطق الرسمي** — لِبيان القواعد
5. **نظرية القرار** — لِترتيب البدائل
6. **نظرية الحوسبة القابلة للنَقض** (Reversibility) — للـ audit trail

أي مكوّن لا يَستخدم هذه الفروع بشكل صريح — **يَتعارض مع هذا الإعلان**.

## ٧. علاقة هذا الإعلان بالأسئلة المعلَّقة

- **Q1 (المركز الديناميكي):** غير متأثر — يَظلّ ساريًا  
- **Q2 (أنماط الحال الخمسة):** غير متأثر — تَظلّ القاعدة  
- **Q3 (موقع اللغة من الإدراك):** **يَتأثر** — اللغة الآن أداة تحليل قابل للقياس، لا وسيط فهم مجهول  
- **Q4 (مكافحة التوسع):** **يَتقوّى** — هذا الإعلان نفسه آلية أنتي-توسعية  

---

## ٨. أثر هذا الإعلان على الميل-ستونات

- **M1** (التحليل اللغوي العميق): يَصبح أولوية أولى لأن التحليل قابل للقياس  
- **M2** (الحوكمة): يَصبح **شرطًا** لا تحسينًا — لا يُسمَح بنشر v1 بدون M2  
- **M3** (الإحالة): يَصبح متاحًا — لكنه يجب أن يَحترم الالتزامات الأربعة  
- **M4** (الاستدلال العملي): يَدخل النطاق رسميًا بحدوده الكمية  
- **ما فوق M4** (تفسير، بلاغة، إعجاز): يَظلّ **خارج النطاق دستوريًا**
