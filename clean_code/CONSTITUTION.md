# الفَصل الأَوَّل — القَواعِد المِعماريَّة الحاكِمَة

## 1.1 لا inline data — كُلّ قاعِدَة في CSV

كُلّ قَواعِد التَّحليل (المَعارِف، الأَفعال، حُروف الجَرّ، الجَزم، الشَّرط، التَّوكيد، القَسَم، التَّقديم) **يَجِب** أَن تَكون مُخَزَّنَة في مَلَفّات CSV تَحت `data/contracts/`، لا في كود Python.

**السَّبَب:** أَيّ قائِمَة مَدمَجَة في الكود = عَقد مَخفيّ. القَواعِد يَجِب أَن تَكون قابِلَة لِلتَّعديل بِدون لَمس الكود.

**التَّطبيق:**
- ✅ `data/contracts/maani/volume1/pronouns_meanings.csv` ← 36 ضَميرًا
- ✅ `data/contracts/lists/operators_catalog.csv` ← 102 عامِلًا
- ❌ `_HARF_NASB_FORMS = ["أَن", "لَن", ...]` (مَرفوض دُستوريًّا)

**Linter دُستوريّ** (`M.8 task #160`) يَفحَص الكود وَ يَرفُض inline lists غَير المَوسومَة.

---

## 1.2 ProofObject pattern — لا نَتيجَة بِلا بُرهان

كُلّ تَحليل يُرجِع **`ProofObject`** يَحوي:

```python
@dataclass
class ProofObject:
    kind: Literal["Certificate", "Hypothesis", "Zero"]
    contract: str            # اسم العَقد المُصدِر
    source_of_claim: str     # المَلَفّ + الصَّفّ
    blockers: list[str]      # ما يَمنَع الإِغلاق
    alternatives: list       # القِراءات البَديلَة المَحفوظَة
    confidence: float        # [0, 1]
```

**الأَنواع الثَّلاثَة:**
- **Certificate** — اكتَمَلَت كُلّ العُقود، لا بَقايا مانِعَة، المَسار مُنفَرِد → إِغلاق مُثبَت
- **Hypothesis** — يوجَد احتِمال تَحليل لَكِن بَقايا أَو نَقص → يَحتاج شَرطًا إِضافيًّا
- **Zero** — يوجَد مانِع قاطِع → فَشَل بُرهانيّ صَريح (لا «تَخمين رَخو»)

**القاعِدَة الذَّهَبيَّة:** كُلّ ادِّعاء يَجِب أَن يُجيب عَن السُّؤال «مِن أَيّ عَقد خَرَجت؟». إِذا لَم تُوجَد إِجابَة داخِليَّة واضِحَة → الِادِّعاء **مَرفوض**.

---

## 1.3 الِالتِزامات الأَربَعَة (Project Scope Declaration)

> «المَشروع يَطمح إلى مُحاكاة تَحليليَّة شَفّافَة قابِلَة لِلحَوكَمَة، لا إلى مُحاكاة فَهم بَشَريّ.»

**1. Source-of-Claim** — كُلّ ادِّعاء مَع مَصدَره (مَلَفّ + صَفّ، أَو قاعِدَة + رَقم سَطر، أَو خُطوَة pipeline). لا «يَعلَم النَّظام» بِلا مَرجِع.

**2. Confidence-of-Claim** — كُلّ ادِّعاء يَحمِل نِسبَة ثِقَة في `[0, 1]`. لا «نَعَم/لا» مُطلَقَة. تُحسَب مِن تَكرار البَيانات + قُوَّة المُطابَقَة + عَدَد الأَدِلَّة + غِياب التَّعارُض.

**3. Alternatives-Preserved** — القِراءات البَديلَة تُحفَظ وَ لا تُحذَف. عِندَ الغُموض → `list[Reading]` مُرَتَّبَة بِالثِّقَة. winner-takes-all مَرفوض.

**4. Reversible-Pipeline** — أَيّ قَرار يُمكِن نَقضه يَدَويًّا، وَ النَّتيجَة تُعاد حِسابها مِن تِلكَ النُّقطَة. لا «صُندوق أَسوَد».

---

## 1.4 نَظَريَّة الحَدّ الأَدنى المُكتَمِل (MC)

> «لا نَبني نِظامًا كَبيرًا ثُمّ نَسأَل هَل يَعمَل، بَل نُحَدِّد أَقَلّ سِلسِلَة عُقود لازِمَة وَ كافِيَة لِإِنتاج شَهادَة صَحيحَة.»

**شَرطا الحَدّ الأَدنى:**
1. **الاكتِمال** — كُلّ مُدخَل داخِل المَجال يَصِل إلى نَتيجَة بُرهانيَّة
2. **الحَدّ الأَدنى** — حَذف أَيّ عَقد يَكسِر الإِغلاق

**اختِبار حَذف العَقد:** «إِذا حَذَفنا هذا العَقد، هَل تَبقى الشَّهادَة صَحيحَة؟»
- بَقِيَت صَحيحَة → العَقد لَيسَ ضَروريًّا (يُحذَف)
- انهارَت → العَقد دُستوريّ

**شُروط إِصدار Certificate:**
```text
Certificate(L) ⇔
    Closed(L)              # اكتَمَلَت العُقود
  ∧ NoBlockers(L)          # لا بَقايا مانِعَة
  ∧ Unique(L)              # المَسار مُنفَرِد
  ∧ SemanticBarrier(L)     # لَم يَدخُل المَعنى المُعجَميّ
```

---

## 1.5 فَصل الـ loader عَن الـ applier

كُلّ مُجَلَّد لَه:
1. **Loader نَحيف** يَقرَأ CSV وَ يُنشِئ indices (`by_vocalized`, `by_plain`, `by_topic_id`, `by_operator`)
2. **Applier فَوقه** يُطَبِّق المَنطِق على النَّصّ

**النَّمَط:** singleton cache في الـ loader، لا state في الـ applier.

```python
# نَمَط الـ loader المُعتَمَد
_CACHE: dict | None = None
def _load() -> dict:
    global _CACHE
    if _CACHE is not None:
        return _CACHE
    # ... بَناء الـ indices مِن CSV
    return _CACHE
```

# الفَصل الثَّاني — القَواعِد اللُّغَويَّة الحاكِمَة

## 2.1 التَّشكيل مَطلوب — العَرَبيَّة المُشَكَّلَة فَقَط

كُلّ مَلَفّات CSV تَستَخدِم **النَّصّ المُشَكَّل** في `vocalized_form`. الفَرق بَين «إِنْ» (الشَّرطيَّة) وَ «إِنَّ» (التَّوكيد) = الفَرق بَين قاعِدَتَين دُستوريَّتَين.

**التَّطبيق:**
- lookup_word يَبحَث في `by_vocalized` أَوَّلًا (مُطابَقَة دَقيقَة)
- إِذا فَشِلَت → `by_plain` كَ fallback
- إِذا وُجِدَت مُطابَقَة مُشَكَّلَة دَقيقَة → **لا plain fallback** (مَنع false positives مِثل إِيَّاكَ vs إِيَّاكِ)

---

## 2.2 NFC Unicode Normalization

القُرآن العُثمانيّ يَكتُب: `ي + ّ + َ` (شَدَّة قَبل الحَرَكَة)
الـ CSVs قَد تَكتُب: `ي + َ + ّ` (حَرَكَة قَبل الشَّدَّة)

**الحَلّ:** `unicodedata.normalize("NFC", s)` في:
1. تَحميل الـ CSV (تَطبيع عِندَ التَّخزين)
2. الـ lookup (تَطبيع المُدخَل)

---

## 2.3 لَفظ الجَلالَة لَفظ مُنفَرِد

> **«اللَّه» لَفظ مُنفَرِد: لا جَذر، لا وَزن، لا كُلِّيّ/جُزئيّ، لا جامِد/مُشتَقّ.**

لا يَدخُل تَحت مَحاوِر التَّصنيف العاديَّة. يُعالَج عَبر `singular_term_detector.csv` كَ exception.

---

## 2.4 عَلامات الوَقف ground truth فَقَط

> **ClauseSegmenter يَجِب أَن يَكون rule-based بالكامِل.**
> **عَلامات الوَقف القُرآنيَّة تُستَخدَم لِلـ eval فَقَط، لا تَدخُل المُدخَل أَبَدًا.**

**السَّبَب:** لَو دَخَلَت عَلامات الوَقف كَمُدخَل، لَن نَقيس قُدرَة الـ segmenter — سَنَقيس نَفسه ضِدّ نَفسه.

**التَّطبيق:** قَواعِد جُملة في CSVs (connectives + conditionals + verb-initial). الـ pause marks كَ ground truth في اختبار صَحيح.

---

## 2.5 الـ root vs wazn vs دَلالَة — طَبَقات مُنفَصِلَة

| الطَّبَقَة | المَلَفّ | الـ output |
|---|---|---|
| التَّطبيع | `normalizer.py` | nfc + لام شَمسيَّة + هَمزَة وَصل |
| التَّقطيع | `segmenter.py` | prefixes / stem / suffixes |
| الجامِد vs المُشتَقّ | `jamid_detector.py` | True/False (vocalized exact) |
| الجَذر | `root_by_alignment.py` | جَذر ثُلاثيّ/رُباعيّ + alternatives |
| الإِعراب | `i3rab_engine.py` | WordClass + Case + Role |
| المَعاني (السَّامَرّائيّ) | `samarrai_analyzer.py` | claims + constructions |

**القاعِدَة:** كُلّ طَبَقَة لا تَتَجاوَز نِطاقها. الـ wazn لا يَدَّعي المَعنى، وَ المَعنى لا يَفتَرِض جَذرًا، وَ الإِعراب لا يَفتَرِض دَلالَة.

# الفَصل الرَّابِع — قَواعِد المُخرَجات

## 4.1 المُخرَجات بِالعَرَبيَّة

> **كُلّ المُخرَجات النِّهائيَّة لِلمُستَخدِم يَجِب أَن تَكون بِالعَرَبيَّة.**

أَسماء التَّوبيك بِالـ ASCII (PREP_BA) لأَنَّها مُعَرِّفات، لَكِن النَّصّ المَعروض (`meaning_ar`) عَرَبيّ كامِل مَشكول.

---

## 4.2 لا تَلفيق أَمثِلَة بِأَلفاظ مُقَدَّسَة

> **«اعتقد ان نظرية... كَتَبَ السَّمَاوَات فِي اللَّهِ ... this not ethical, you are trying to fool me, dont ever do this again»**

**القاعِدَة:** أَيّ مَثَل مُحَتَوي عَلى لَفظ الجَلالَة أَو أَسماء قُرآنيَّة يَجِب أَن يَكون:
1. **مَنقولًا حَرفيًّا** مِن القُرآن (مَع `surah_ayah` و `example_quran`)
2. أَو **مُؤَلَّفًا بَريئًا** بِدون أَلفاظ مُقَدَّسَة (في `example_constructed`)

لا يُسمَح بِتَأليف جُمَل تَخلُط لَفظ الجَلالَة مَع مَفاهيم خارِجيَّة لِأَغراض الشَّرح.

---

## 4.3 hash لا يَكون source-of-claim

> **«ادعاء بدون اختبار قبول قابل للقياس = ادعاء بدون مصدر = انتهاك MC»**
> **«hash must not be source-of-claim»**

الـ hash يُستَخدَم لِلتَّحَقُّق مِن السَّلامَة، لا لِلِاستِدلال. أَيّ ادِّعاء يُسَنَد إلى hash بِدون CSV/قاعِدَة = انتِهاك دُستوريّ.

# الفَصل الخامِس — قَواعِد التَّنفيذ التَّشغيليَّة

## 5.1 lookup سِياسَة (lookup policy)

```python
def lookup_word(word, require_vocalized=True):
    # 1. مُحاوَلَة المُشَكَّل أَوَّلًا
    if word in by_vocalized:
        return by_vocalized[word]      # ← مُطابَقَة دَقيقَة، لا fallback
    # 2. عِندَ الفَشَل فَقَط → plain fallback
    plain = _normalize(word)
    if plain in by_plain:
        return by_plain[plain]
    return []
```

**سَبَب القاعِدَة:** لَو طَبَّقنا fallback دائِمًا → إِيَّاكَ (مُذَكَّر) يَتَطابَق مَع إِيَّاكِ (مُؤَنَّث) لأنّ الـ plain لِكُلَيهِما «اياك».

---

## 5.2 الـ singleton cache

كُلّ loader يُحَمَّل **مَرَّة واحِدَة** عِندَ أَوَّل استِدعاء، ثُمّ يُحفَظ في `_CACHE` على مُستَوى المُوديل.

**السَّبَب:** القُرآن كامِلًا يُحَلَّل في 2.5 ثانيَة (2,531 آية/ث). بِلا cache: ~30 دَقيقَة.

# الفَصل السَّادِس — قَواعِد التَّوسيع وَ الصِّيانَة

## 6.1 إِضافَة قاعِدَة جَديدَة

1. **حَدِّد المُجَلَّد** (volume1-4) وَ المَلَفّ المُناسِب
2. **أَضِف صَفًّا في CSV** بِكُلّ الأَعمِدَة الإِلزاميَّة (vocalized_form, meaning_id, meaning_ar, source_part, source_page, confidence, author_position)
3. **اختَبِر** بِـ `python3 samarrai_loaders/volume{N}_loader.py`
4. **لا حاجَة لِتَعديل الكود** — الـ loader يَلتَقِط الصَّفّ الجَديد تِلقائيًّا

---

## 6.2 إِضافَة تَركيب جَديد (construction)

التَّراكيب (مِثل TAQDIM، TAHZHEER) قَواعِد بِنَمَط لا بِكَلِمَة. لِإِضافَة تَركيب:

1. أَضِف الـ rule كَ row في `volume{N}/taqdim_takhir.csv` (operator=—)
2. أَضِف دالَّة كَشف في `samarrai_analyzer.detect_constructions()` تَفحَص النَّمَط
3. الدَّالَّة تُرجِع `ConstructionMatch(claim, span_words, pattern_name)`

---

## 6.3 إِضافَة مُجَلَّد خامِس (Volume 5)

1. أَنشِئ `data/contracts/maani/volume5/*.csv` بِنَفس الـ schema
2. أَنشِئ `samarrai_loaders/volume5_loader.py` (انسَخ القالَب مِن volume4)
3. أَضِف في `samarrai_loaders/__init__.py`: `from . import volume5_loader`
4. حَدِّث `samarrai_analyzer.lookup_word_all_volumes()` لِيَستَدعي volume5
5. `python3 samarrai_analyzer.py --stats` لِلتَّأكيد

# الفَصل التَّاسِع — دُروس التَّجريب (Lessons Learned)

## 9.1 من ذاكِرَة المَشروع

- **«hash must not be source-of-claim»** — Hash لِلتَّحَقُّق لا لِلِاستِدلال
- **«pause marks ground truth only»** — Segmenter يَستَنِد لِقَواعِد، الـ pause marks لِلـ eval
- **«Jalalah is singular term»** — لَفظ الجَلالَة خارِج مَحاوِر التَّصنيف
- **«validated judgments worth saving»** — حَفظ القَرارات الصَّحيحَة كَما حَفظ التَّصحيحات

## 9.2 سُلوكيَّات يَجِب اجتِنابها

- ❌ تَأليف أَمثِلَة بِأَلفاظ مُقَدَّسَة لِشَرح فِكرَة
- ❌ إِضافَة مَراحِل بِلا ضَرورَة في الـ pipeline
- ❌ إِصدار نَتائِج بِلا دَليل داخِليّ
- ❌ خَلط التَّحليل الشَّكليّ بِالمَعنى أَو الحَدس
- ❌ winner-takes-all (حَذف القِراءات البَديلَة)
- ❌ إِرجاع UNKNOWN عِندَ الفَشَل (يَجِب إِرجاع Zero صَريحًا)

## 9.3 سُلوكيَّات مَطلوبَة

- ✅ كُلّ تَحليل يَنتَهي بِـ ProofObject
- ✅ كُلّ صَفّ في CSV لَه source_part + source_page
- ✅ القَواعِد التَّركيبيَّة تَحمِل `operator=—` (لا يُطلَقها lookup كَلِمَة)
- ✅ NFC على المُدخَل وَ المُخَزَّن
- ✅ singleton cache في الـ loaders
- ✅ التَّفريق بَين Certificate (إِغلاق)، Hypothesis (احتِمال)، Zero (فَشَل صَريح)
