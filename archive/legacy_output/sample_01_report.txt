Architecture Test — Sample 01
اختبار تطبيقي للمعمار على نص قرآني قصير
========================================================================
Reference : Quran 94:6 (الشرح 6)
Text      : ﴿إِنَّ مَعَ الْعُسْرِ يُسْرًا﴾
Context   : 94:5 repeats the same sentence

────────────────────────────────────────────────────────────────────────
STEP 1 — Meaning Flow (03)
────────────────────────────────────────────────────────────────────────
Path: sign → attention → initial_conception → possibility_space → evidence_gathering → relation_building → weighing → designation → meaning_construction → inference → understanding

Sign → Attention:
  • Four lexical units in sequence: إنّ • مع • العسر • يسرًا
  • Tawkid at onset (إنّ) — not ordinary informative clause
  • مع signals accompaniment between two entities
  • Contrast: العسر definite, يسرًا indefinite with tanwin

Initial conception: Nominal construction with إنّ fronted; structural rule, not event narrative

Possibility space:
  ? Is مع locative, temporal, or preposition?
  ? Is يسرًا fronted khabar, maf'ul, or tamyiz?
  ? Why definite العسر vs indefinite يسرًا?
  ? Is order إنّ + delayed ism + fronted khabar?

Evidence:
  • إنّ requires mansub ism + marfu' khabar; يسرًا is mansub → not marfu' khabar
  • Resolution: ism of إنّ = يسرًا (delayed); khabar = PP مع العسر
  • مع: accompaniment (locative/temporal metaphor)
  • ال on العسر: genus (jins), not deixis
  • Tanwin on يسرًا: type / multiplicity of ease

Relations:
  • إنّ → structural tawkid state on whole clause
  • مع → accompaniment between العسر and يسر
  • العسر / يسر → abstract bearers (genus vs type)

Weighing: Preferred: with every hardship (as genus) there is ease (type or types). Prior ayah 94:5 repeats the same form → insistence on rule.

Meaning: Affirmed structural rule: hardship (universal genus) is paired with ease (type/types)

Understanding: Affirmed structural informative rule: hardship–ease coupling (94:6)

────────────────────────────────────────────────────────────────────────
STEP 2 — Layer-Centric Decomposition (01)
────────────────────────────────────────────────────────────────────────
  ● Sign: 4 vocalized units + diacritics/tanwin; no constitutional retrofit
  ● Perception: Tawkid vs plain statement; definite vs indefinite; adverb vs harf
  ● Relation: مع → accompaniment; إنّ → tawkid relation on propositional content
  ○ Event_Transformation: INACTIVE — no finite verb; purely nominal/static composition
  ● Context: 94:5 repetition strengthens rule-reading; surah theme: taysir
  ● Resolution: العسر → genus via al-; يسرًا → type/multiplicity via tanwin + nasb
  ● Time: No explicit tense; rule framed as timeless; مع allows time/place reading
  ● Identity: العسر as genus-identity; يسر as type-identity
  ● Reasoning: Hardship is bounded by co-present ease (not unqualified hardship)

Note: Ayah strongly activates static layers; Event/Transformation dormant — discovery, not failure

────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────

Definite hardship (one genus) vs indefinite ease (type/multiplicity) — architecture holds via Resolution + Identity layers
